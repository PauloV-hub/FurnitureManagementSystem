# 🛋️ Furniture Management System

Web system developed in **C#** and **.NET** for managing a furniture store, including orders, furniture, and customer control.

![Project Status](https://img.shields.io/badge/status-in_development-yellow)

---

## 📝 About the Project

This project was created to help small and medium-sized furniture store owners manage their operations with a complete system.

---

## ✨ Main Features

* [x] Customer Registration (full CRUD)
* [x] Product Registration (furniture)
* [x] Sales Order Generation
* [ ] Inventory Control (incoming and outgoing stock)

---

## 🚀 Technologies Used

* **Backend:** C# (ASP.NET Core)
* **Frontend:** HTML/CSS
* **Database:** SQLite  
* **IDE:** Visual Studio 2022

---

## 🔧 How to Run the Project

Follow the steps below to run the project locally.

### Prerequisites

* [.NET SDK 9.0.305](https://dotnet.microsoft.com/download)
* [Visual Studio 2022](https://visualstudio.microsoft.com/vs/community/)
* [SQLite](https://sqlite.org/download.html)

### Step-by-Step

1. Clone the repository:
    ```bash
    git clone https://github.com/PauloV-hub/FurnitureManagementSystem.git
    ```
2. Open the solution file (`.sln`) in Visual Studio.  
3. Configure the database connection string in the `appsettings.json` file.  
4. Run the migrations to create the database (if using Entity Framework):
    ```bash
    dotnet ef database update
    ```
5. Run the project (by pressing **F5** or clicking the **"Play"** button).
